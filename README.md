# Pagina_Gestion_De_Incidentes

Landing page responsive para presentar una aplicación de escritorio de gestión de incidentes, pensada para industrias y fábricas.

**Nexo** Está construido con HTML, CSS y JavaScript.

## Archivos

- `index.html`: contenido y estructura de la página.
- `styles.css`: estilos, componentes.
- `script.js`: menú móvil, ampliación de capturas y formulario de demo.
- `assets/`: capturas de la aplicación.
